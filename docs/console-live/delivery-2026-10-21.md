## 官方 Hermes 与登录边界

固定研究与兼容基线仍是未修改官方 Hermes `427d605d4985c2d49a795493ef6c5d66413057d1`。API Server 的 Enable/auth key/port/host/model name 是业务入口，默认端口 8642；`hermes serve` 管理 REST 与 WebSocket/RPC 默认 9119，身份与认证契约不同。业务 `/v1/models` 通过不会把 Profile 管理标为通过。
