## 故障与修复边界

固定上游原生元数据读取使用保存的 session 账号；实际登录账号改变后，该值可能与活动进程不一致。WeChat PR15 使用经过进程、环境和数据库 FD 校验的唯一活动账号，供 fresh auth 及联系人、会话、消息元数据读取；身份未知、歧义或读取期间改变时拒绝继续。没有改写保存的 session 身份、删除旧密钥、重置游标、退出账号、重新启动微信或修改发送路径。

Gateway 同步现在拒绝把一个已绑定来源改写为另一账号；新账号必须有自己的来源记录。目录条目按来源、账号、稳定微信标识隔离，消息事件摘要包含账号、会话及消息身份，增量游标按来源与账号限定。候选权限仍不覆盖正式权限。旧来源的采集保留停用状态。

单个会话读取失败不再中断其他正常会话；系统页显示部分采集与失败阶段。诊断仅保存白名单原因码、计数、观察时间、最近正常时间及有界恢复记录，不保存消息正文或原始异常。浏览器收到增量响应、正文渲染和会话摘要更新分别记录；收到响应不代表正文已经显示，也不代表其他终端已显示。

单条已归档消息可展开处理详情，读取该消息现有的发生、上游可读、归档、增量、准入、权限、路由、Hermes、结果和投递记录。没有记录的阶段显示未核验；仅归档的消息明确不执行 AI。文件工具阶段仍未核验，不从当前候选员工配置反推正式权限，也不因打开详情创建或重派任务。
