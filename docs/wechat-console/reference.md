# WeFlow 公开布局参考记录

2026-10-21，只读查看了 [WeFlow 官网](https://weflow.top/)、其公开展示图，以及 [hicccc77/WeFlow](https://github.com/hicccc77/WeFlow/tree/fb58afa9876c6b334887a33471dd5f0077eedec4) 固定提交 `fb58afa9876c6b334887a33471dd5f0077eedec4` 的 README、LICENSE 和公开联系人/聊天组件的标签与结构。

该版本 [LICENSE](https://github.com/hicccc77/WeFlow/blob/fb58afa9876c6b334887a33471dd5f0077eedec4/LICENSE) 为 **CC BY-NC-SA 4.0**。本候选只参考固定侧栏、搜索分类、紧凑联系人列表、独立详情区和聊天列表加阅读面板这些通用交互布局，没有复制 WeFlow 的代码、CSS、图标、图片或其他资产，没有安装 WeFlow，也没有将其作为依赖。

实际观察中的区分也保留在实现中：备注、昵称和稳定 username 分开；来源覆盖范围明确标注；聊天仅阅读已有档案，联系人详情不能推断不存在的群成员资料。官网展示图主要介绍报告、分析和导出，固定 README 的 `app.jpg` 是宣传 banner，未将这些图片描述成经过核对的聊天详情截图。

本仓库的 HTML、CSS、JavaScript、CF 标识和 SVG 图标均为本轮独立编写。合成结果截图见 [证据索引](README.md)，不包含 WeFlow 资产。
