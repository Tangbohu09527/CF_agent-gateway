# 微信管理台候选交付（2026-10-21）

管理员可以从通讯录和已发现群识别对象、查看已归档消息，再登记员工、设置两级权限和分组，无需先知道数据库编号。候选已经在 CFserver 独立运行；管理设置只写候选数据库，不影响正式机器人。真实微信当前为 `app_not_running`，页面明确显示“来源离线 · 已读取缓存”，未恢复微信。

## 入口与使用

局域网入口为 `https://<CFserver-LAN-IP>:18445/console`，准确内网地址和登录说明在本轮私有交付消息提供，不将其及凭据提交公共仓库。服务运行于 CFserver，脱离 Windows 终端；无需启动本机演示。登录使用本轮经用户授权初始化的用户名和密码，服务器仅保存 PBKDF2 哈希。

2026-10-21 已按用户明确许可，将服务器现有公开 CF CA 加入本机 **CurrentUser** Root。未修改 LocalMachine 信任存储、未导出服务器私钥、未关闭证书校验。其他管理电脑需通过可信方式信任同一现有 CA；不能忽略浏览器证书告警。

最短路径：登录 → 通讯录搜索备注/昵称/微信号/稳定标识 → 查看 → 关联员工 → 确认姓名、两级权限和员工分组。已发现群 → 查看 → 登记群并分组。分组与模板页配置模板及已登记电脑；没有经过验证的 Hermes 连接时，Profile 动作显示真实不可用或失败，不返回假成功。

本轮没有任意挑选真实好友授予权限。真实页面只读核对和打开表单；完整登记、授权、分组与持久化写入流程在合成数据的实际后端和页面上验证。
